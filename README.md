# 新标签页编辑器（Chrome 扩展）

把 Chrome 的新标签页变成一个本地文本编辑器：即开即写、自动保存、可导出，零依赖、无需联网。每个新标签页会自动编号为 txt1、txt2、txt3…，内容彼此独立。编号与内容为**会话级存储**：浏览器运行期间持续累加编号、自动保存内容；**完全退出浏览器后自动清空，下次启动从 txt1 重新开始**。

## 文件结构

```
chrome-newtab-editor/
├── icons/              # 扩展图标（16/32/48/128 PNG）
├── manifest.json       # 扩展清单：声明接管 newtab 页面
├── newtab.html         # 编辑器界面（textarea + 顶栏）
├── newtab.js           # 加载 / 自动保存 / 字数统计 / 导出
└── generate-icons.py   # 生成图标的脚本（可改颜色/图案后重新运行）
```

## 浏览器启动与「会话恢复」

扩展不主动拦截也不主动恢复启动时的标签页——这件事完全由 Chrome 自己处理：

- **Chrome 启动设置是「打开新标签页」**：启动时会自动打开一个空 newtab，被扩展接管后变成 txt1 标签页。
- **Chrome 启动设置是「继续浏览上次打开的网页」**：关闭 Chrome 前打开着的所有标签页（包括 txtN 编辑器）会被 Chrome 原样恢复。

要实现「关闭浏览器时打开着 TXT1，重启后继续打开 TXT1」，请把 Chrome 启动设置改为「继续浏览上次打开的网页」。

## 工作原理

- `manifest.json` 里的 `chrome_url_overrides.newtab` 把默认新标签页替换成 `newtab.html`。
- 每个标签页打开时从会话计数器分配编号（txt1、txt2、txt3…），顶栏与浏览器标签页标题同步显示。
- 编号计数器与内容都存于 `chrome.storage.session`（内存级）：浏览器运行期间累加、保存，**完全退出浏览器后自动清空**，因此重启后重新从 txt1 开始。
- 内容按编号独立存储（`note_N`），因此每个新标签页初始都是空白，不会带入上一个标签页的内容。
- 输入停止 300ms 后自动保存；顶部实时显示字数；「导出 .txt」会以当前编号命名（如 `txt3.txt`）。

## 安装步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 并回车。
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本文件夹（`chrome-newtab-editor/`）。
5. 新建一个标签页（`Ctrl+T`），即可看到编辑器。

### 离线 / 公司电脑安装

本扩展无构建步骤、无外部依赖，只需把整个 `chrome-newtab-editor/` 文件夹拷贝到目标机器，重复上面第 1~4 步即可，全程不需要联网。

## 常见问题

| 问题 | 说明 |
|------|------|
| 新标签页没变化 | 确认「开发者模式」已开，且加载的是包含 `manifest.json` 的文件夹（不是它的上一级目录） |
| 内容会永久保存吗 | 不会。编号与内容存于 `chrome.storage.session`（内存），浏览器完全退出即清空、重启后从 txt1 重新开始。如需长期保留，请用「导出 .txt」 |
| 还能显示 Google 搜索框吗 | 不能，`newtab` 被完全替换。需要搜索可在顶栏自行加一个跳转输入框 |
| 为什么用 `chrome.storage.session` 而不是 `local` | `session` 是 Chrome 的会话级存储，浏览器退出自动清空，正好满足「重启归零编号」的需求；数据不出本机、无需账号 |
| 关闭浏览器时打开着 TXT1，重启后会自动恢复吗 | 这取决于 Chrome 自己的启动设置。请把 Chrome 设置改为「继续浏览上次打开的网页」（`chrome://settings/onStartup`）。扩展本身不参与会话恢复 |

## 图标自定义

扩展图标已接入 `manifest.json` 的 `icons` 字段，并同步配置了 `action.default_icon`（工具栏图标）。

- 当前样式：暗色圆角方形底 `#2B2B2B` + 白色字母 `T`（Georgia 衬线）。
  - 大图标（48/128）：regular 细体，衬线优雅。
  - 小图标（16/32）：bold——小尺寸下细体笔画不足 1px，抗锯齿会被稀释成灰色，加粗才能保证纯白清晰。
- 重新生成图标需要 Pillow（扩展运行时只加载 PNG，不需要）：`pip install Pillow`
- 想改颜色/字体/字母：编辑 `generate-icons.py` 顶部的 `BG`（背景色）、`FG`（字母色）、`FONT_CANDIDATES`（字体路径）、`TEXT`（字母）变量，然后运行：

```bash
python generate-icons.py
```

脚本会用系统字体重新生成 16/32/48/128 四档 PNG，刷新扩展后即可生效。

## 可选增强方向

- Markdown 实时预览：引入 `marked.js`，左写右渲染
- 笔记列表 / 历史：提供一个界面列出已编号的 txtN 笔记，支持切换查看和删除
- 行号 / 代码高亮：接入 `CodeMirror` 或 `Monaco` 编辑器内核
